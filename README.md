# More Brutal Slavery | 更残酷的奴隶制

Victoria 3 Mod，版本 0.1.0，支持游戏版本 1.13.x。

## 安装

正式 Mod 位于 `mod/Slavery Gameplay/`。手动安装时，将整个 `Slavery Gameplay` 文件夹放入 Victoria 3 用户目录的 `mod` 文件夹，再在 Paradox 启动器中启用。请保留文件夹内部的 `.metadata` 目录。

GitHub Release 的安装包应下载单独附加的 `More-Brutal-Slavery-v0.1.0.zip`。GitHub 自动生成的 “Source code” ZIP 包含仓库目录结构，不是安装包。

## English

Victoria 3 mod, version 0.1.0; supported game version 1.13.x.

The installable mod is in `mod/Slavery Gameplay/`. For manual installation, place the entire `Slavery Gameplay` folder in your Victoria 3 user `mod` directory, then enable it in the Paradox launcher. Keep the `.metadata` directory inside the mod folder.

For a downloadable package, use the separately attached `More-Brutal-Slavery-v0.1.0.zip` release asset. GitHub's automatic “Source code” ZIP includes the repository layout and is not the installation package.
